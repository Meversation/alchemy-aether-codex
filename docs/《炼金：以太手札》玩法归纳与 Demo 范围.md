# 《炼金：以太手札》玩法归纳与 Demo 范围

> 英文名：Alchemy: Aether Codex  
> 平台：Fabric 1.21.1  
> 核心：蒸馏三元素，绘制符文，记录手札。  
> 本文档用于整理完整玩法愿景，并明确当前精力下只做 Demo 的边界。

---

## 一、完整玩法愿景（未来目标）

### 核心循环

探索获取原料 → 蒸馏坩埚炼金 → 解锁符文 → 绘制施法 → 记录以太手札 → 建造符文刻印 → 挑战禁忌法术 → 炼金造物 → 贤者之石。

### 系统概览

| 系统         | 说明                                                   |
| ------------ | ------------------------------------------------------ |
| **三元素**   | 水银、硫磺、盐，可加工为精华、合金、粉尘等             |
| **符文绘制** | 铭刻杖在空中画图案，匹配后释放法术；分基础、复合、禁忌 |
| **以太手札** | 记录已解锁配方、符文、发现；可升级扩页                 |
| **废弃小屋** | 探索起点，获取破旧铭刻杖与无名手札                     |
| **意外火药** | 硫磺+盐+水银在坩埚加热时爆炸，掉落火药，手札记录       |
| **符文刻印** | 在方块上刻符文，组合成陷阱、结界、装饰                 |
| **炼金造物** | 用坩埚创造生物，可养成、装备、指令                     |
| **禁忌法术** | 灵魂抽取、生命转化等，有永久代价                       |
| **贤者之石** | 终极目标，持续产出精华，点石成金                       |

---

## 二、Demo 目标（精力有限，只做这些）

### Demo 核心体验

验证一个最小循环：**捡到水银 → 放入坩埚 → 意外爆炸 → 发现火药 → 手札记录 → 用铭刻杖施放一个基础法术。**

### Demo 内容清单

- [ ] **项目基础**：Fabric 1.21.1 空模组跑通，能进入游戏
- [ ] **物品注册**：
  - 铭刻杖（简化版，可直接获得，无需修复）
  - 水银滴（击杀生物掉落）
  - 硫磺粉、盐晶（可暂用原版物品替代，或简单注册）
  - 以太手札（空白书，获得后自动记录）
- [ ] **方块注册**：
  - 蒸馏坩埚（一个自定义方块，可交互）
- [ ] **坩埚交互**：
  - 右键投入物品
  - 下方有火时加热
  - 若同时存在硫磺+盐+水银 → 触发爆炸事件
  - 否则产出少量精华（可暂用简单逻辑）
- [ ] **爆炸事件**：
  - 不伤害玩家、不破坏方块
  - 三色粒子 + 三个音效叠加
  - 掉落 1-3 个火药
  - 手札自动记录“黑火药”页
- [ ] **手札记录**：
  - 首次获得关键物品时，在聊天栏或物品描述中提示
  - 爆炸后解锁一页文本（可用原版书与笔或简单 GUI 显示）
- [ ] **基础符文施法（简化）**：
  - 不做复杂轨迹识别
  - 右键铭刻杖可切换/释放一个照明法术（或推拉法术）
  - 验证“施法”的感觉
- [ ] **测试场景**：
  - 用指令放置一个简易小屋（原版方块）
  - 内含箱子：破旧铭刻杖 + 水银滴 ×3 + 无名手札
- [ ] **占位纹理**：
  - 坩埚：炼药锅改色
  - 铭刻杖：木棍 + 发光宝石色块
  - 手札：书改色
  - 三元素：简单色块

### Demo 明确不做

- ❌ 符文刻印系统
- ❌ 炼金造物 / 生物
- ❌ 禁忌法术
- ❌ 贤者之石
- ❌ 复杂手札 GUI（用原版书或聊天栏代替）
- ❌ 自定义小屋结构生成（用指令放置）
- ❌ 精细纹理绘制（占位即可）
- ❌ 完整符文轨迹绘制（用右键简化）

## 三、开发优先级 Checklist

1. Fabric 项目跑通，能进入游戏
2. 注册铭刻杖、水银滴、以太手札

4. 水银滴掉落（击杀生物）

7. 手札记录（聊天栏提示 + 书页文本）
8. 简化符文施法（右键铭刻杖触发照明）
9. 用指令搭一个小屋作为测试场景
10. 画占位纹理并替换
