# 《炼金：以太手札》学习路线表

## 总览

| 阶段 | 时间 | 目标 | 检验标准 |
|---|---|---|---|
| Java 基础 | 第 1-2 周 | 能读懂 Fabric 示例代码 | 写出控制台版炼金系统 |
| Fabric 入门 | 第 3-4 周 | 物品、方块、方块实体 | 游戏里能拿到自定义物品和方块 |
| 核心功能 | 第 5-6 周 | 坩埚爆炸 + 手札记录 + 施法 | Demo 能完整跑通 |
| 打磨打包 | 第 7 周 | 优化 + 打包 | 生成 jar 给朋友玩 |

## 第 1 周：Java 最小必要知识

| 天 | 学什么 | 具体内容 | 练习 | 免费资源 |
|---|---|---|---|---|
| 周六上午 | 变量与类型 | int、double、String、boolean | 定义符文名称、消耗值、是否解锁 | 《Think Java》第 1-2 章 |
| 周六下午 | 条件与循环 | if/else、for、while | 遍历符文列表，输出已解锁的 | 《Think Java》第 3-4 章 |
| 周日上午 | 类与对象 | class、字段、方法、构造器 | 写 Rune 类：名字、消耗、效果 | 《Think Java》第 5-6 章 |
| 周日下午 | 继承与接口 | extends、implements、@Override | 写 BasicRune extends Rune | 《Think Java》第 8-9 章 |
| 工作日 | 集合 | List、Map、泛型 | 用 List<Rune> 管理所有符文 | 赫尔辛基慕课第 1-3 部分 |

## 需要跳过的内容

| 内容 | 原因 |
|---|---|
| Java 多线程 | Fabric 模组开发用不到 |
| Java 网络编程 | Fabric 有自己的一套 |
| Java Swing/JavaFX | 你是做 Minecraft GUI，不是桌面应用 |
| 设计模式（大部分） | 初期用不到，后期遇到再学 |
| Kotlin | 你已经决定用 Java |
| NeoForge | 内存不够，专心 Fabric |
